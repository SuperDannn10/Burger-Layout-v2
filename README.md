# Tasty Burger

A modern restaurant website for discovering Tasty Burger's craft burgers, fries, and story.

## About

Tasty Burger is a burger restaurant website concept. Visitors can browse the menu, learn about the restaurant, and find information for planning a visit.

## Sections

- **Home** — an introduction to Tasty Burger
- **Menu** — featured burgers and sides
- **Our Story** — the restaurant's story and approach

## Development

To run the site locally, install the project dependencies using its configured package manager, then start the development server using the script defined in `package.json`.
